# ObamaTech - Vitrine Digital

## Sobre o projeto

O **ObamaTech - Vitrine Digital** é uma landing page moderna de uma plataforma fictícia de cursos e e-books de tecnologia. O projeto foi desenvolvido com foco em **HTML, CSS e JavaScript puro**, utilizando boas práticas de responsividade, design moderno e renderização dinâmica de produtos.

---

## Objetivo

Criar uma vitrine digital interativa onde os produtos são carregados dinamicamente via JavaScript, simulando uma plataforma real de venda de cursos e conteúdos digitais.

---

## Tecnologias utilizadas

* HTML5
* CSS3 (Flexbox + Grid + Responsividade)
* JavaScript (DOM + eventos + renderização dinâmica)
* Google Fonts
* Font Awesome

---

## Funcionalidades

* Layout moderno e responsivo
* Hero section com destaque principal
* Lista de produtos renderizada via JavaScript
* Cards dinâmicos com imagem, preço e descrição
* Sistema simples de “Adicionar ao carrinho” (alert)
* Newsletter com validação básica
* Menu de navegação com rolagem suave
